# M–C Waves

## Common return contract

Each M/C wave uses [`../RETURN-CONTRACT.md`](../RETURN-CONTRACT.md) and
`../return.schema.json`; this is not a second schema. Demo and closure proof
stay in named `annexes.demo`/`annexes.closure` artifacts. Every dependency,
report, gate receipt/output, annex and π/DELTA coordinate joins the exact
ordered state-artifact union and repository-derived digest.

Audit-only waves make no implementation changes. Every dependency cell contains
only literal wave IDs. A range, prose condition or implicit owner is invalid.
