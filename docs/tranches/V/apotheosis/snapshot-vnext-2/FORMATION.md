193-wave owner registry and the bounds authority's fifteen declared Git roots

authenticates declared structure, shape and path law; it does not assert that a
declared root or subpath is currently present. Live resolution classifies each
required root as included when present or unavailable when absent; a required
root can never be excluded. A required subpath under an unavailable root is
inherited blocked, while a subpath under an available root must exist with its
exact realpath and containment.

For every consumer edge, an unavailable source requires an unavailable edge
with zero observations. An available source targeting an unavailable internal
root requires an unavailable edge with the exact source observations. No other
edge may be unavailable, and an included edge requires an included source and
included internal target. Duplicate canonical realpaths, escaped subpaths,
unknown roots or owners, incomplete discovery, unverified evidence and any
violation of those disposition/observation laws fail closed.

C00U **COMPLETE** means exit 0, `resolvable:true` and an empty blocker vector.

vector and an exact routed remainder; it never advances to C05. C05 is a fresh
post-migration resolution and requires exit 0, `resolvable:true` and no

## Canonical application state

Each application has one state authority and one codec implementation.

```ts
interface UrlEnvelope<Route extends string, State> {
    v: 1;
    route: Route;
    state: State;
}
```

Rules:

- The readable route remains in the hash path.
- The encoded state contains only deviations from route defaults.
- Encoding is deterministic and versioned.
- Decoding validates route, depth, field count, numbers, enums and total length.
- Invalid, oversized or future state produces an explicit recover/reset state.
- Continuous drag/slider/scrub/gesture updates live only in runtime preview;
  they do not write committed state, URL or history.
- A settled semantic commit pushes exactly once when canonical state changed;
  cancel writes nothing.
- Popstate never writes the same state back recursively.
- Credentials, session tokens and unauthorized private resource data never enter URLs.
- Value resource sharing uses stable revision or explicit share resources.
- Keyframes has no share server; state exceeding the URL bound is explicitly refused or exported locally.
