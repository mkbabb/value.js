## 1. Total-tranche / gestalt analysis

The selected shape fits the reset architecture. `consumeNumber` is a regular,
context-free leaf operation within the `value-unit` numeric family; it is not a
reason to introduce a lexer, token tape, atom, component-value, CST, source
cursor, or balanced scanner. H2 expresses that leaf with one published
parse-that `regex` terminal and one adjacent semantic projection. Percentage,
dimension, integer-only policy, delimiters, and complete-input policy remain
parent productions, so this selection neither steals ownership from those
modules nor creates a god primitive.

The selection also fits the acknowledged BBNF-family direction: a normative
numeric leaf belongs below value-unit consumers and should be composed by
higher productions. A single regular terminal here is more idiomatic than
expanding the same finite recognizer into a ceremonial parser graph. Accepting
this leaf does not establish stylesheet reachability, full CSS coverage, public
API shape, integration, or production credit; those remain downstream work.

No tranche-level rescope follows from the candidate comparison. The useful
general rule is narrow: retain combinator structure where composition carries
grammar meaning, but permit a single regex terminal for a genuinely regular
CSS leaf when the entire language and projection remain readable at sight.

## 3. Feature analysis

H2 implements the CSS consume-number shape directly:

`[+-]? ( digits+ ('.' digits+)? | '.' digits+ ) ([Ee] [+-]? digits+)?`

The map derives only the three owned semantic fields: explicit sign, integer
versus number classification, and numeric value. The parser is constructed
once at module scope. It neither consumes a delimiter nor imposes end-of-input,
which is required for parent composition. Incomplete exponents and repeated
fractions remain outside the matched prefix rather than being swallowed. The
bound evidence covers those cases, transactional failure, UTF-16 offsets,
descriptors, hostile inputs, repeated calls, and parser-identity stability.

I found no confirmed architectural, idiomaticity, readability, ownership, or
selection-binding defect in the exact subject. The small wording ambiguity in
“smallest direct grammar shape” is not a false byte-count claim: the detailed
axis records the 17-line tie, and the exact source sizes make the seven-byte H
difference explicit.
