object-key-order dependence, no Unicode normalization, no non-finite JSON
number, and every digest string lowercase 64-character hexadecimal. Raw source
bytes use canonical base64. `SHA256` returns 32 digest bytes; `hex()` returns lowercase
hexadecimal; `hexToBytes()` accepts exactly 64 lowercase hexadecimal
characters.

Numeric values use this closed trichotomy:

- A schema/control count, zero-based index, enum ordinal, subject count, block
  count, sample count, exponent, `N`, `pilotN`, or other non-observational
  mathematically integral schema field is a JSON number only when it is a
  non-negative safe integer (`0 ≤ x ≤ 2^53-1`); overflow is structural RED.
- Every exact observed unsigned integer counter—including raw monotonic clock
  ticks/nanoseconds, ingress bytes, UTF units/code points, tokens, nodes,
  diagnostics, allocations, retained bytes, and deterministic-work counts—is
  exactly `u64be:` followed by sixteen lowercase hexadecimal digits encoding
  the unsigned 64-bit big-endian value, even below `2^53`. Overflow is invalid
  evidence. Decode to an exact unsigned integer/BigInt and perform counter
  arithmetic exactly. Conversion to ECMAScript `Number` is permitted only
  after proving the value safe; otherwise the frozen limit/invalidity law
  controls. A duration may retain raw start/end/delta counters beside its
  required derived scalar, but statistics consume only that scalar.
- Every finite duration, timestamp delta, median, per-pass value, sample,
  throughput, ratio, logarithm, exponential, aggregate, deviation,
  coefficient, slope, bound, interval endpoint, quantile, derived memory or
  allocation statistic, and other continuous or derived scalar is the exact
  IEEE-754 binary64 bit string `f64be:` followed by sixteen lowercase
  hexadecimal digits in big-endian byte order. This string is
  `f64beScalar`.

Encode an `f64beScalar` from the pinned ECMAScript `Number`'s raw big-endian
IEEE-754 binary64 bytes. Decode those exact bits, perform arithmetic,
comparisons, `log`, and `exp` only under the pinned Node/V8 runtime, and encode
the resulting bits again. Decimal parsing conventions, rounding, fixed
precision, locale, and JSON-number spelling do not participate; signed zero is
preserved. NaN and positive/negative infinity have no scalar encoding. Pilot
raw timer/duration failure maps to `TIMER_OR_DURATION_NONFINITE`; pilot derived
failure maps to `PILOT_DERIVATION_INVALID`; T9 raw or derived measurement
failure maps to `MEASUREMENT_NONFINITE`. No implementation may clamp, coerce,
omit, or stringify a non-finite value.
