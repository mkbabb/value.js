# `KF-SELECTOR` boundary challenge A — REJECT

**Seat:** independent specification/contract skeptic, 2026-07-22.  
**Disposition:** REJECT the proposed feature row before candidate authoring.

## Total-tranche finding

The lexerless direct-combinator architecture is sound, but the proposed
keyframe selector row is not the smallest independently closable feature. It
presupposes unsettled CSS identifier/trivia, percentage, percentage-valued
math, source mapping, diagnostics, serialization, list composition, and public
compatibility decisions.

## Wave/row finding

The ledger must distinguish at least:

1. the singular normative selector;
2. the nonempty comma-separated selector list;
3. the public compatibility/type adapter.

The normative observation type is not frozen. It must decide whether `from`
and `to` remain explicit alternatives, how literal and percentage-valued math
are represented without premature IEEE-754 loss, how raw spelling/spans are
observed, and the exact seven-name union with a mandatory named offset.

CSS Values percentage-valued math cannot be blanket-rejected merely because
one browser door rejects it. Likewise, a syntactically valid exponent whose
mathematical value exceeds JavaScript's finite `number` range needs an
explicit carrier/limit policy rather than accidental rejection.

## Feature findings

- Freeze CSS preprocessing, escapes, ASCII-insensitive keyword matching,
  comment handling, complete-input behavior, and original-source offsets.
- Freeze an exact diagnostic observation schema before comparing candidates.
- Split singular grammar serialization, selector-list serialization, and
  public/CSSOM compatibility serialization.
- Benchmark the grammar-only observation door separately from the public
  adapter. The live regex peer needs a common-domain lane and cannot receive
  full corrected-domain credit.
- Treat browser results as witnesses, not the arbiter: observed engines differ
  on percentage-valued math and unsupported named-range syntax.

No implementation bytes were reviewed or accepted.
