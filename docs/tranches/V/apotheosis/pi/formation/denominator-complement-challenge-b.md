## Altitude 1 — total-tranche / gestalt challenge

The source-universe pass is a good discovery front end, and source-level
routing can precede operation ownership. A terminal or quasi-terminal
exclusion decision cannot. The declared precedence is currently:

1. snapshot/meta;
2. terminal/superseded/non-language exclusion candidate;
3. dependency candidate;
4. later/experimental candidate;
5. unresolved.

That ordering asks source status to outrank syntax. In this tranche the owner
has expressly included experimental facilities, and the operation denominator
must be non-lossy. “Abandoned”, “not adopted”, “not maintained”, or “may move”
can establish maturity; none proves that a production is absent, duplicated in
a successor, or outside the owner extension. The artifact further says only
the 26 dependency and 38 later/experimental candidates proceed to occurrence
review. The 13 exclusion candidates receive an “exact exclusion reason”
challenge, which can pass while unique grammar is silently dropped.

The optimal order is instead:

1. establish exact source identity and distinguish aggregation/redirect-only
   bytes from substantive bytes;
2. run a parser-surface occurrence inventory over **every substantive source**,
   including every exclusion candidate;
3. resolve imports/normative citations to a fixed point;
4. for every supersession or migration claim, compare each production and
   algorithm occurrence against a content-addressed successor owner;
5. classify no-parser-surface, duplicated/superseded, normative dependency,
   experimental/owner-extension, or unresolved;
6. challenge exclusions and unresolved rows, then seal the denominator.

Source classification remains useful as a work queue, but the current queue
has a false-negative branch. It therefore cannot become PB0's denominator
input unchanged.
