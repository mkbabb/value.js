## Scope and method

- **Code home**: `pi/mirror/` — self-contained package (own package.json,
  vitest, tsx), seeded from the frozen assay snapshot. Phase-A compatibility
  modules remain in their existing homes; Phase B lives behind
  `mirror/l4/index.ts` and is split by the PB0-derived owner lattice. Directory
  names are semantic ownership, not one-file-per-production ceremony.
- **Parse-that baseline and uplift rule**: consume
  `@mkbabb/parse-that@1.0.0` EXACT until a content-addressed BBNF/parse-that
  exchange identifies an uplift as fully implemented and hardened, the local
  prototype independently reproduces its correctness and performance evidence,
  and an E-3 addendum explicitly changes the pin or authorizes an idiomatic
  local use. No engine source is edited or silently vendored by this tranche.
- **Transpose, don't reinvent**: live `src/css/` is the semantic oracle
  (1607 lines: grammar/stylesheet/timeline/syntax). Types, serializers,
  `coerceToSyntax`, and the `collect*` walkers transpose from live near-
  verbatim (they are not regex-parsing code); the PARSING core is authored as
  parse-that combinators. Spec (Color 4/Easing 1/Syntax 3/scroll-animations)
  overrides live where they conflict (the R1–R5 class).
- **Perf built in, not retrofitted** (`../parser-proof/PROFILE-ANALYSIS.md`):
  every feature's three direct-combinator candidates run the same
  correctness-qualified micro/corpus comparison. `dispatch()`, fused
  composition, memoization, and specialized terminal regexes are candidate
  choices only when their grammar remains readable and measurement proves the
  benefit. Raw evidence and comparator identities are retained; no shared
  lexical substrate or benchmark-only fast path is admitted.
- **Freeze-parity**: adjudicated at formation by the harden seat — equivalence
  is structural value-equality; `deepFreeze` is live's implementation detail
  and the mirror does NOT pay it unless a consumer is shown to rely on
  frozen-ness (harden seat verifies against kf + demo usage).
