# waves/K-A.md

## Common wave return contract

Every K/A wave returns the complete canonical record in
[`../RETURN-CONTRACT.md`](../RETURN-CONTRACT.md) and validates it against
`../return.schema.json`; this list is not a second schema. K/A-specific proof
lives under `annexes.keyframes` or `annexes.api`. All six terminal/audit
statuses, pins, born-RED, DAG, gate, API, visual, performance, limit, consumer,
disposition, operation-vector, remainder and self-hash fields remain required.

Audit-only waves return evidence and routed defects but make no source repair.
