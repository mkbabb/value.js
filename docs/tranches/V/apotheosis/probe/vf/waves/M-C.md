# M–C Waves

## Common return contract

Each M/C wave returns the complete canonical record in
[`../RETURN-CONTRACT.md`](../RETURN-CONTRACT.md) and validates it against
`../return.schema.json`; this paragraph is not a second schema. Demo-specific
proof lives under `annexes.demo`; closure-specific proof lives under
`annexes.closure`. Pins, born-RED, DAG, gate, visual, performance, consumer,
remainder, typed absence and self-hash fields remain required.

Audit-only waves make no implementation changes. Every dependency cell contains
only literal wave IDs. A range, prose condition or implicit owner is invalid.
