# Formation

## Charter

This is tranche formation and its execution specification. Production source work begins only from a converged wave and never from an unresolved branch.

The two seed letters are the complete root context:

- `../coordination/keyframes-inbox-2026-07-18-vnext-ingestion-prompt.md`
- `../coordination/keyframes-inbox-2026-07-18-vnext-formation-handoff.md`

Deep evidence is pulled only by the wave that needs it. The quarantined `vnext/r1-opus-refuted/` corpus is never loaded.

All formation critics are Sol. Every wave is challenged by two fresh hostile Sol perspectives and a third fresh Sol adjudicator. The adjudicator agglomerates the alternatives, proves or disproves each finding against evidence, and ameliorates the wave before it can close. Luna is reserved for future mechanical implementation fanout after formation; it does not adjudicate formation. A clean close requires two consecutive fresh passes with no new mechanism.

Execution repeats the thrice method at the smaller, useful grain. Every terminal
implementation return binds one final-state triad: two fresh hostile Sol-ultra
passes, each covering tranche fit/optimality, wave-contract adherence/friction
and feature behavior, followed by a third fresh Sol-ultra adjudicator. Any
finding reopens its exact owner; any repair invalidates the reviewed repository
state and forces a fresh triad. C08/C09 then challenge the whole landed corpus
twice again and never substitute for the per-wave close.

## Canonical application state

Each application has one state authority and one codec implementation.

```ts
interface UrlEnvelope<Route extends string, State> {
    v: 1;
    route: Route;
    state: State;
}
```

Rules:

- The readable route remains in the hash path.
- The encoded state contains only deviations from route defaults.
- Encoding is deterministic and versioned.
- Decoding validates route, depth, field count, numbers, enums and total length.
- Invalid, oversized or future state produces an explicit recover/reset state.
- Continuous drag/slider/scrub/gesture updates live only in runtime preview;
  they do not write committed state, URL or history.
- A settled semantic commit pushes exactly once when canonical state changed;
  cancel writes nothing.
- Popstate never writes the same state back recursively.
- Credentials, session tokens and unauthorized private resource data never enter URLs.
- Value resource sharing uses stable revision or explicit share resources.
- Keyframes has no share server; state exceeding the URL bound is explicitly refused or exported locally.
