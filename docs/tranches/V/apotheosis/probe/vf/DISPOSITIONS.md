# Binding Dispositions

## Parser substrate

| Surface | Disposition | Owner | Binding consequence |
|---|---|---|---|
| Published parse-that surface | **Keep as prototype substrate** | P00, P01 | The complete full-CSS prototype installs the exact public 1.0.0 tarball; no raw/private/workspace path is a workaround. |
| Prototype-blocking defects | **Bank and route; no local repair** | P02, P03 | Each P01 CSS RED is minimized, banked uncommitted in parse-that, and routed to the active campaign. Value remains on published 1.0.0 or blocks adoption. |
| parse-that release | **No release** | P04–P07, C10 | Published 1.0.0 receives one no-link `no-rc` receipt and is never republished. Any blocker remains with the active campaign and blocks V-next pending a separately authorized epoch. |
| New run/result model or `RunContext` | **Route externally** | P02, PT-E/BBNF handoff | Opaque parser, `Parser.state` removal, raw-API removal, new result model, or general memo/recovery redesign is not authorized here. |
| Tape/SoA in parse-that | **Route externally** | PT-E/BBNF handoff | No generic or internal Tape/SoA substrate experiment enters this tranche. |
| SoA in color kernels | **Terminal evidence decision** | V16B | It may land only for a named completed bulk/mix/ramp pipeline with real end-to-end benefit. Scalar caller-owned-output kernels remain canonical. |
| Pratt in parse-that or BBNF | **Route externally** | PT-E/BBNF handoff | No Pratt framework or novelty trial enters P00–P07. Value V05 may use only the existing parse-that surface and its own adjudicated value grammar. |
| Diagnostics/recovery defects | **Bank and route** | P02, P03 | Accumulation, nested rollback, and EOF evidence remain banked; none authorizes a Value-session parse-that mutation. |
| Core/entry/module-format redesign | **Route externally** | PT-E/BBNF handoff | SCC cuts, ESM-only conversion, export-condition identity, and major package topology reset belong to the separate session. |
| BBNF host/emitter/grammar uplift | **Execution predecessor, never runtime dependency** | PT-E/BBNF handoff, P00 | BBNF owns the terminal CSS union and resolved module/edge receipt consumed by P00/P01; Value imports no active host/emitter/runtime novelty. |
