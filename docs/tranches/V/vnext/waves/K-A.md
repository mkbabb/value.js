# waves/K-A.md

## Common wave return contract

Every K/A wave uses [`../RETURN-CONTRACT.md`](../RETURN-CONTRACT.md) and
`../return.schema.json`; this is not a second schema. K/A proof stays under the
named `annexes.keyframes` or `annexes.api` artifact, and every dependency,
report, gate receipt/output, annex and π/DELTA coordinate joins the exact ordered
state-artifact union and repository-derived digest.

Audit-only waves return evidence and routed defects but make no source repair.
