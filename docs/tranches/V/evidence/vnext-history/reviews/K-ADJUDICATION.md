The current standards surface was checked against primary editor drafts:

- [Web Animations Level 1](https://drafts.csswg.org/web-animations-1/);
- [Web Animations Level 2](https://drafts.csswg.org/web-animations-2/);

- [Scroll-driven Animations Level 1](https://drafts.csswg.org/scroll-animations-1/).

The imperative `AnimationTrigger` behavior enum and ranges in Web Animations 2
are distinct from the CSS trigger/action grammar in Animation Triggers 1.
K04I inventories both standards graphs; V28 owns CSS syntax while K08 owns
imperative delegation/refusal.

## Binding architecture

### Program and drivers

- `ProgramSpec` is immutable, JSON/JCS-safe and contains no DOM object.
- `ResolvedAnimationPlan` is target-realm-bound and nonserializable.
- Ready tracks use exactly `waapi` or `raf` drivers.  CSS compilation returns
  `CompiledStylesheet`, which `play()` cannot consume.
- A required refusal, dependency violation or property-write conflict produces
  no plan.  Only an optional independent track declared before compilation may
  be omitted, with its refusal retained.
- One injected clock owns rAF.  Native WAAPI is never shadowed or silently
  rerouted.

### Standards and value authority

K04I generates total pinned WebIDL/operation facts, WPT selection and browser
profiles before K04.  Every generated row receives exactly one reviewed
implemented/delegated/refused/not-applicable result on the appropriate axis and a non-vacuous construction/WPT
vector.

V29T freezes six direct value paths:

```text
./color  ./css  ./easing  ./math  ./path  ./transform
```

`./value` and `./quantize` are tombstoned.  V29T emits a hashed
`value-public-surface.json` mapping specifier, symbol, type/runtime kind,
source/declaration/runtime targets, tarball SHA-512 and API semantic hash.
Every K edge installs that exact tarball and uses only those paths.
