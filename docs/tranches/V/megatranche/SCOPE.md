## §2 — THE APOTHEOSIS SHAPE (M-4), the unit of work in this formation

Every item — component, library module, wave row, addendum clause — passes through exactly this:

```
        ┌── CHALLENGE-D  "the DESIGN is flawed"
item ───┼── CHALLENGE-L  "the LIBRARY is improperly structured"
        └── CHALLENGE-C  "the COMPONENT is improperly implemented"
                              ↓ (all three, independent, no shared conclusions)
        ┌── JUROR-1  correctness + evidence
        ├── JUROR-2  architecture + isomorphism
        └── JUROR-3  design + gestalt + performance
                              ↓
              RE-AUTHORED ADDENDUM + RE-AUTHORED WAVE SPEC
```

Laws binding the shape:

1. **The challengers begin from guilt.** Each is told the item IS defective on its axis and must
   find the defect. A challenger returning "no defect found" must prove the negative with the same
   evidence standard a positive finding requires — bytes, a probe, a measurement.
2. **The challengers are blind to each other** and to any favored narrative about the item.
3. **The jury may not merely rate.** Its deliverable is the *re-authored* addendum and wave spec.
   A jury that returns a verdict without a rewritten spec has not discharged its seat.
4. **Born-RED wherever the defect is live.** A wave whose defect reproduces today opens RED and
   its gate must fail against today's tree. A gate that passes at authorship is vacuous.
5. **π and DELTA obligations attach to every visual claim.** No visual assertion ships without a
   named capture obligation (π = the pinned witness, DELTA = the before/after pair).
6. **Every seat declares `model: 'opus'`.**
