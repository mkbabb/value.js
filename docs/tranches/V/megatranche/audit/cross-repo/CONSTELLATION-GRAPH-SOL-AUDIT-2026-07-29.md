## Exact amendments

### 1. Break the parse-that/Value release cycle

Value V.L1/V.L5 currently require a signed successor release before
implementation, while parse-that forbids release until Value CSS and a second
non-CSS grammar consume the substrate.

Smallest route:

1. produce one immutable unpublished parse-that candidate tarball;
2. consume it in Value and one same-primitive non-CSS grammar;
3. prove deletion, equivalent output, formal ≥10× CI-low and clean audits;
4. release parse-that;
5. rebind and retest Value against the released coordinate.

Raw-source aliases remain forbidden. BBNF receives its ABI receipt only after
W3 freeze and may not create a CSS parser.

Parse-that also needs one canonical parent/wave set owning candidate pack,
Value receipt, named second grammar, deletion, formal performance, release and
BBNF receipt. The root parser addendum remains explicitly superseded and
cannot serve as that authority.

### 2. Separate package checks from formal release proof

Current parse subpath checks require `/utils` even though its exports lack
proven consumers or a terminal removal disposition. Current `proof:perf`
thresholds are regression/dispatch guards, not the user's formal ≥10×
equal-semantic CI-low gate.

KEEP them as current-package checks only. The successor release wave owns:

- the separate formal ≥10× admission proof at every binding scale;
- equivalent semantic products;
- per-export consumer proof;
- `/utils` removal if two real consumers do not exist.

### 3. Make Value closure depend on real Keyframes receipts

V.L6 cannot close because Keyframes “can” migrate. It closes only after:

1. W2 exact adoption and local grammar/scanner/serializer deletion;
2. W3 immutable tarball and tier/evaluation proof;
3. the cross-repo row remains open through the W10 Atlas crater.

### 4. Replace Keyframes W7's incomplete Glass gate

Fresh import resolution is insufficient because Glass watch currently omits
declarations/component CSS and standalone style/font inputs.

W7 acceptance must consume the producer lifecycle's complete
JS/declaration/CSS/style/font manifest and mutation closure. No consumer
source link or raw alias may substitute.

### 5. Delete resurrected F-L2 analyzer cadence

Fourier W12 scope prunes the wrapper/analyzers, but its cadence still says to
run “F-L2 analyzers.” Replace that instruction with the direct compiler/Vite,
real client/FastAPI, deployed transport and Playwright controls from XR-15.

### 6. Normalize artifact identity

- Candidate packs may support tranche development.
- Published immutable tarballs/tags and exact SHA receipts close release
  consumption.
- Final Value closure requires published Glass 8, not any mutable full build.
- Keyframes `v6.0.0` is annotated but cryptographically unsigned; name the tag
  object/commit and exact pack SHA rather than “signed v6.”
