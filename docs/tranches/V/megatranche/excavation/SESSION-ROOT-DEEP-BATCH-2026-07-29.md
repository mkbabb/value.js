This ledger adjudicates session evidence against the current tree, commits, and
the megatranche truth registers. A prompt, assistant close, rehearsal archive,
or green workflow claim is evidence of intent or a historical state. It is not
implementation proof by itself.

task and parent where metadata records them. Three user roots and 97 delegated
or guardian roots fall inside that newest-100 window. This does not relabel
delegated work as owner work.

are excluded. The binding table therefore contains exactly 111 session-root
rows.

Dispositions use only `IMPLEMENTED`, `PARTIAL`, `FORMATION-ONLY`, `REJECTED`,
`SUPERSEDED`, and `NO-ACTION`. `WALL` and `NO-CLOSE` describe the terminal
session evidence, not a disposition.
