# Value Boundary Prototype

Status: ISOLATED FORMATION PROTOTYPE — NEVER PRODUCT SOURCE

This directory models two Value boundary families:

- the still-open CSS/path/transform ownership and failure-explicit inverse
  contracts;
- the root-agglomerated palette policy and per-object release-membership
  constraints.

It has no parser, serializer, scanner, persistence implementation, package
export, build entry, raw-source alias, or compatibility path. P2 has been
agglomerated as AMEND: placement and a narrow grounded operation set are
frozen, while illustrative record shapes remain quarantined here. The API
types encode constraints folded from the rejected P3 candidate; they are not a
second route authority.

`contract.ts` demonstrates constraints, not frozen signatures. It records the
terminal typed-only total `PathGeometry` constructor and compile-RED string
constructor, while leaving SVG command/span, transform/motion, issue, and CSS
stop shapes to fail-capable execution cells.
