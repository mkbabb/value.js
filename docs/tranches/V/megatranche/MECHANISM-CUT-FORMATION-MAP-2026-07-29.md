### Shared dispatch, disjointness, cadence, and close law

This dated map is evidence for later formation, not a completed specification. After the blockers
close, the owner pins an unused tranche letter and the surviving cuts are re-authored—not merely
copied—into canonical `docs/tranches/{LETTER}/waves/W<N>.md` files. No cut may become
`in_progress` while it lives only under the provisional `V·MT*` labels.

Unless a wave overrides the row, its dispatch is three serial seats:

| unit | title | access | goal | sub-gate |
|---|---|---|---|---|
| `.a` | Mechanism implementation | one GPT Luna xhigh writer | land the bounded mechanism and delete its old path | focused build/tests and declared born-RED gates green |
| `.b` | Gestalt challenge | GPT Sol xhigh read-only | attack tranche fit, wave optimality, and feature behavior | every finding is evidenced and dispositioned |
| `.c` | Refutation and close | GPT Sol xhigh documentation-only writer | refute implementation and challenge, then author one terminal verdict | goal and completion criteria reconciled; docs/current state agree |

Only `.a` writes product source. `.b` is read-only. `.c` may write the wave’s evidence/status
documents but not product source. Therefore no two units share a source `modify` path and no
parallel writer worktree is required. If `.a` executes away from the primary tree, its reserved
path is `/Users/mkbabb/Programming/value.js-{LETTER}-w<N>-a`; no other unit may use it.

The following conditions trigger a triumvirate and halt isolated redispatch:

1. file bounds expand by more than two paths;
2. a hard-gate failure requires a different mechanism or cross-repo producer edit;
3. the same diagnostic loop reaches a third iteration;
4. a wave would need an alias, shim, dual path, masking fallback, or unconsumed substrate;
5. the goal can no longer be met even if every listed gate passes.

Cadence after every integration batch and again at close:

```text
npm run build

git diff --check -- <wave-owned-paths>
```

Visual waves also run `npm run gh-pages` and their in-app Browser π cells. Release-equivalent E2E

`docs/tranches/{LETTER}/artefacts/W<N>/`; exact stdout, packed-artifact probes, screenshots,

Commit checkpoints use Conventional Commits with concrete mechanism scopes: one `.a`

and one close/status commit. Broad, deletion, generated, benchmark, gate, and status commits carry
bodies with why, what, evidence, and routed remainder. No AI/tool authorship. The wave document
