## How to read this register

- Each finding reached its row through two seats: an audit seat and a fresh confirm seat. Only **CONFIRMED (C)** and **AMENDED (A)** findings are listed. Where the confirm seat amended the owner, severity, mechanism or fix, the row uses the amended version. **M** marks a miss the confirm seat found and added. **P** marks a mechanism that is plausible but was not proven in-browser; each P row says which probe would settle it.
- **One row per root cause.** 436 raw audit findings (437 confirm verdicts: loaded-image-mode returned 23 verdicts for 22 findings) plus 142 confirm-seat misses collapse into the 256 rows below. When one defect showed up on several pages (for example the CarouselPager crash, the dead `/v/` route, the 390 dock cap, the `1×` spill, the Dialog radius, and the top-anchored Toaster), the row lists every page and names one representative frame.
- **Owner:** `CONSUMER` means fourier-analysis. `GLASS` means glass-ui, and those rows go to the glass-ui session to be fixed at the root, per the owner's order. `SERVER` means the fourier API. A split owner such as `GLASS + CONSUMER` lists the glass half first.
- Rows are ordered by severity, BROKEN → HIGH → MEDIUM → LOW. The GLASS relay index at the end lists every row that has a glass part.
