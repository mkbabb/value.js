## Why
`.gap` and `.gap2` (X.P.W7 addenda (h)–(j)) found valid CSS the product refuses by reading real sheets. That is sampling, not coverage. This wave makes coverage systematic.

## Scope
1. **Corpus:** vendor the WPT `css/` parsing tests for the value-bearing modules the product claims: css-values-4 (math, url, attr, units), css-grid-2 (`<line-names>`, `<track-list>` including the minified forms like `[a]1fr[b]`), css-images-4 (`element()`, gradients, `image-set()`), css-fonts-4 (`unicode-range` `<urange>`), css-transforms-2, css-easing-2, css-color-5 (already partly in), css-variables-1, and css-syntax-3's tokenizer edge cases. Use the `*-valid.html` and `*-invalid.html` `test_valid_value` / `test_invalid_value` cases, extracted by a committed script into dated JSON (E-3), in the way the css-color corpus already is.
2. **Gate V-C (conformance):** for every in-scope property/value case, a valid case parses and round-trips to WPT's expected serialization (or a named, ruled serialization difference), and an invalid case is refused. Each miss is cured in BBNF or recorded as a ruled out-of-scope row with its spec reason. There are no skips without a row.
3. **Named known misses at mint:** `[top]auto[stage]1fr[bottom]auto` (line names with no whitespace), `attr(data-x type(<length>))`, `element(#a)`, `U+0025-00FF`, and `<custom-ident>` looseness in `coerceToSyntax` (strings and `*` accepted; `[a]` matching `<custom-ident>`).
4. **Stay-GREEN:** L-G2 equivalence, where every new delta row is a named class with a repair test; the prefix equivalence at 0; L-G3; the size ceilings; `test:css-equivalence` with 0 mirror defects; vue-tsc, eslint and the build.
5. **Speed at close:** L-G1 ×2 re-read on the final bytes in an orchestrator quiet window (X.P.W7 addendum (g) cells and protocol).
