### 3b. The architecture candidates (novel research, M-25 — named, with predicted failure modes)

These are this author arm's candidates — **not** a transcription of the pause handoff; the
handoff names the hypothesis, not the architectures. Each candidate is a concrete way to be ONE
algebra with two lowerings; each carries the failure modes I predict will kill it, so the
harness is built to look exactly there first (L-19: a gate must be able to fail for its intended
reason).

**AC-1 — TAGLESS-TWIN (typed final encoding).** The grammar is authored once against a typed
signature of algebra operations; lowering-JS instantiates the signature with the combinator
library's own constructors (the interpretation IS the shipped parser — source-direct, no
codegen); lowering-Wasm instantiates the same signature with an emitter that assembles a
zero-import module (linear memory: input bytes in, value arena out). Predicted failure modes:
(a) **signature leak** — the union of both targets' needs grows a target-conditional or a
target-only primitive, at which point there are two algebras wearing one interface (K-2 is
written for exactly this); (b) **megamorphic IC collapse** — final encoding means every
combinator call site sees per-instantiation closure shapes; V8's inline caches go megamorphic on
the hot path and the source-direct premise dies on the short-string leg (G-6's accepted leg +
`--trace-ic` in §3d watches for it); (c) **continuation inexpressibility** — first-class
recovery ops (resync, rollback) that lean on captured continuations cannot lower to zero-import
Wasm without the stack-switching proposal; if recovery only works in JS, K-3/K-4 kill it.

**AC-2 — CLOSED-IR (initial encoding, grammar-as-data).** The algebra is a finite closed union
of IR node kinds — the grammar as one authenticated data object (this is the OR04/OR05 closed-
union law made load-bearing: every kind/variant a closed authenticated union, no fallback,
handoff §8 step 5). Lowering-JS compiles the IR **once at module init** into a combinator graph
on the library surface; lowering-Wasm compiles the same IR ahead-of-time into module bytes.
Predicted failure modes: (a) **double-interpretation tax** — if init-time compilation is not
total and any node falls back to per-parse IR dispatch, JS throughput lands at interpreter
speed and the accepted leg shows it; (b) **the escape-hatch node** — the hard 20 %
(var()/relative-color context nodes, the balanced tail) tempts a `hostFn` node holding a JS
closure; the moment one node kind has exactly one lowering, dual-target is dead by construction
(K-3 enumerates the bijection); (c) **label drift** — provenance/diagnostics equality requires
the labels to live IN the IR; labels synthesized per-backend diverge byte-wise and G-3's
diagnostics product catches it.

**AC-3 — SPAN-ALGEBRA (scan/parse split; the SIMD-scan/lex union inside the combinator
library).** A branchless char-class scanner (typed-array class table; scalar JS loop shaped for
auto-vectorization; the identical table under `v128` SIMD in the Wasm lowering, scalar
fallback) produces token spans; the algebra's terminals are span-class matchers, and the scanner
itself is a combinator-library citizen (parse-that owns it — scannerless surface preserved,
scanning an internal fusion). Predicted failure modes: (a) **token-boundary divergence** — CSS
color microsyntax is context-sensitive at exactly the adjudicated juxtaposition rows
(`rgb(50%20%30%)`, `rgb(1.5.5 3)`, `hsl(120 50%50%)`) and the numeric edge rows (`1.`, `1e400`);
one boundary disagreement with the css-syntax token reading on any universe row and G-3's
semantic product kills it; (b) **short-string inversion** — the scan prelude's setup cost
dominates at the median ~20-char single-color hot path and wins only on sheets; the prior
evidence says short strings are already the closer leg (value 0.0640 vs sheet 0.0537), so this
candidate is predicted to optimize the wrong end — G-6's per-leg print makes the inversion
undeniable if it happens; (c) **arena latch** — span-buffer reuse across parses is global
mutable state, the PT-03 class (a one-way latch cost parse-that 1.47× forever); K-6 kills any
candidate whose parse #100,001 can be distinguished from parse #1.

**AC-0 — GENERATOR (named non-candidate, pre-killed at formation).** The BUILD-V12 shape — one
builder emitting both targets — is NOT evaluated. Its falsifier family is already terminal on

- **Wasm audit**: `WebAssembly.Module.imports(mod).length === 0`; exports enumerated closed;

- **Depth**: the deep-nesting corpus row (nested `var(var(…))` past 10,000) returns `ok:false`
