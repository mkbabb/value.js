### 3b. The algebra — the normative object (laws fixed here; enumeration left to the blind drafts)

The algebra is **not** a combinator library and **not** a grammar DSL: it is a closed set of typed
operators over a four-part state, with laws both lowerings must satisfy observably. This section
fixes the **laws and capability families** (corpus-derived, non-negotiable); the exact operator
enumeration, naming, and count are what `.a` and `.b` author blind and `.c` ratifies — pinning the
full operator set here would make phase 1's blindness theater.

**State.** A parse of input `S` is a function to `(V, C, P, D)`:

| part | what it is | why it is separate |
|---|---|---|
| **V** — semantic value | exactly the frozen `/css` value types, **zero** extra properties | the no-CST claim made checkable: `V` is assignable to the frozen types under an excess-property check (G-10) |
| **C** — byte complement | ordered `(offset, length, kind)` for every byte of `S` **not** injected into `V` — whitespace, comments, case spelling, separator choice, skipped malformed spans | the CST is exactly `(V, C)` fused into one tree; splitting them is what lets `V` be a plain value |
| **P** — provenance | a side table from `V`'s construction-ordered leaf index to `(start, end)` in `S` | provenance without tree position; an array, not a node field |
| **D** — diagnostic journal | an append-only ordered list of `ParseIssue` values (the frozen 8-code union, `src/css/types.ts:10-24`) | diagnostics are **values, never effects** (R-LAW-3) |

**Law COMP-1 (conservation / the malformed inverse).** For **every** `S` in the closed universe —
accepted or malformed — `weave(V, C, P) === S`, byte for byte. This subsumes "byte complement" and
"malformed inverse" in one falsifiable law, and it is why recovery cannot be an escape hatch:
bytes skipped by recovery land in `C` or the law breaks.

**Capability families the closed operator set must cover** (from the blind arms' union; the drafts
enumerate the operators): sequence · ordered committed choice · token-class scan · span-into-`C` ·
channel-table dispatch · value construction with provenance append · clamp · exact scale
(`(value * num) / den`) · labelled zero-width failure with named expectations · bounded back-edge
(the depth bound an **algebra parameter**) · commit point · mark/rollback · recover/resync with
declared synchronization. Any tree-shaped carrier of input syntax in any draft is a draft defect.

**O-8 (the anti-latch construction rule).** No operator reads or writes process-global mutable
state. Arming, memoization, and diagnostics are **parameters of a parse**, never latches. PT-03
made law: a one-way `PACKRAT_ARMED` costing 1.47× forever, whose reset does not disarm, is a state
machine with one absorbing state — and no algebra with a global absorbing state can satisfy EQ-1
across two lowerings that arm at different times.

**The six equality products (EQ-1..EQ-6)** — identical in both blind arms, ratified here:

| id | product | comparison | "exact" means |
|---|---|---|---|
| EQ-1 | semantic value `V` | structural deep-equal | **bit-for-bit f64** via `Object.is` (−0 and NaN distinguished), never epsilon |
| EQ-2 | byte complement `C` | ordered list equality | same order, same `(offset, length, kind)`; `weave` round-trips both |
| EQ-3 | provenance `P` | ordered `(start,end)` array equality | leaf construction order must match — forcing both lowerings to build `V` in the same order |
| EQ-4 | diagnostics `D` | ordered **structural** equality | `code` / `start` / `end` / `expected[]` / `actual` — **not rendered strings** (byte-equal rendered messages across a JS and a Wasm backend is a trap: number formatting, locale, allocation; the rendered string is a non-normative presentation layer outside the algebra). A candidate whose labels exist only under an armed-diagnostics mode reads as diagnostics-ABSENT and fails (PT-01). |
| EQ-5 | rollback | post-failure state equality | offset, journal length, complement length (and Wasm arena watermark) restored to pre-mark values; **cost asymmetry is declared, not equalized** — value is normative, cost is reported (G-8) |
| EQ-6 | malformed inverse | COMP-1 on the malformed corpus | `weave(V, C, P) === S` for every `ok:false` input |

Comparison mechanism: a canonical structural serialization per product, byte-compared — the
Fable arm's mechanism carrying the Opus arm's semantics.

**The five recovery laws (executable probes, G-4):**

- **R-LAW-1 — rollback exactness.** On failure inside recovery, the restored state is exactly the
  pre-mark state: offset, journal length, complement length, (Wasm) arena watermark. The lowerings
  may differ in **cost** (arena truncation vs an allocation-free JS failing path) but never in
  value; the algebra declares this asymmetry.
- **R-LAW-2 — complement conservation.** Bytes skipped by recovery enter `C`; they never vanish.
  COMP-1 holds on malformed input.
- **R-LAW-3 — diagnostic purity.** A diagnostic is a value appended to `D`, never an effect. The
  probe monkey-patches `console.error`/`console.warn` to **throw** over the full corpus — a
  lowering that prints cannot pass (the PT-01 coupling made unpassable).
- **R-LAW-4 — non-amplification and progress.** `N` malformed sites yield exactly `N` diagnostics;
  `sync` must consume ≥1 byte or recovery does not re-enter. The probe uses a `sync` matching at
  offset 0 of the failure — a lowering that hangs or emits `N²` fails.
- **R-LAW-5 — the `alt`/`recover` interaction, declared.** A recovered branch is a **success** for
  the enclosing choice, so a first arm that recovers starves the second. The contract states the
  rule (forbid recovery inside a non-final choice arm, or declare the alternative) — leaving it
  undeclared is how a lenient parser silently stops being total.

**Contract details held load-bearing**: `ParseResult`'s failure arm is
`{ ok: false; diagnostics: readonly [ParseIssue, ...ParseIssue[]] }` (`src/css/types.ts:27`) — a
**non-empty tuple**; the frozen contract already forbids the PT-07 shape (`undefined`-on-failure)
at the type level, making "every rejection carries ≥1 diagnostic" a contract obligation.

**Declared marks (carried, never silently picked; each with an owner-escalation path in

### 3c. The candidate field (novel research, M-25 — fixed at `.c`, grown never)

**AC-1 — TAGLESS-TWIN (typed final encoding).** The grammar is authored once against a typed
signature of algebra operations; lowering-JS instantiates the signature with the combinator
library's own constructors (the interpretation IS the shipped parser — source-direct, no codegen);
lowering-Wasm instantiates the same signature with an emitter that assembles a zero-import module

the union of both targets' needs grows a target-conditional or target-only primitive; two algebras
