## 2. Goal criterion

This wave succeeds if every control a user can operate in the persistent shell and on the Gradient
rail is a real, named, reachable semantic control at a legal target size, and if the application
has exactly one typed way to name and dispatch a scene's actions — so that a control that cannot be
operated, or an action that silently does nothing, becomes unrepresentable rather than merely
absent from the current build.

**Baseline provenance.** Every number marked *measured* was taken read-only on **2026-08-03**
against the live dev stack (`http://localhost:9000`, HTTP 200) with Playwright 1.60.0/chromium, at
1440×900 (fine) and 390×844 (`isMobile`+`hasTouch`, `matchMedia("(pointer: coarse)")` = true),
on `/` and `/#/gradient`. The census rule, replayed at wave open:

```text
selector: button,[role=button],a[href],input,select,textarea,[role=tab],[role=slider],
          [role=checkbox],[role=switch],[role=menuitem],[tabindex]:not([tabindex="-1"])
visible:  rect.w>0 && rect.h>0 && visibility!=hidden && display!=none
name:     aria-label > aria-labelledby text > textContent > title > img[alt]   (placeholder is NOT a name)
```

**Attribution rule (binding on A1/A2).** For a composite widget the measured target is the element
that owns the pointer and keyboard contract, not its visual sub-part. The four `.slider-thumb`
spans that MT-F004 booked at 12×24 / 12×44 resolve to their `.channel-slider` root, *measured*
