## 2 · THE FOUR TRAPS — a discriminator is MANDATORY (4 records)

A trap is a probe **both hypotheses satisfy**. Running one without its discriminator manufactures a
**false confirmation**. §Surface-list protocol 5: *a probe satisfied by both hypotheses is a **spec
defect**, not a measurement.* Each row below therefore carries a **DISCRIMINATOR** (the observation
that separates the hypotheses) and a **FALSIFIER** (what would kill the row).

  BOTH arms render a Curve-labelled node.** Seeing a node labelled "Curve" proves **nothing** about
  which arm rendered it. §H's exemplar for the whole gate.

  versus a **bare `div`** (the `inline` arm). Read the role/tag, never the label.

  arm and re-opens D-8 and D-17's rider. The kill's prediction is `allControlTabs.length ∈ {0,3,4}`,
  **never 1** — a measured length of 1 falsifies the enumeration outright.
- **Standing**: the discriminating test was *handed to KF.W9* by name at `:23`.
